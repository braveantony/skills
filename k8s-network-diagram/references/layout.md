# 版面

畫布是 `viewBox="0 0 1280 720"`。以下座標都以此為準。

## 節點

節點是並排的黑框矩形，上緣 y=24，底邊 y=544，彼此間距 80。

| 節點數 | 每個寬度 | 起始 x | 每節點標註上限 |
|---|---|---|---|
| 2 | 570 | 30、680 | 4 |
| 3 | 370 | 30、455、880 | 2 |
| 4 以上 | 拆成多張圖 | | |

節點太多時硬塞會讓文字小到看不清，拆成「總覽」加「單一路徑細節」兩張比較好。

## 雲

底部置中，約 x=490–790、y=570–700，由一個橢圓加數個圓疊成。成員網卡以黑色曲線連入雲；曲線先畫、雲後畫，讓線尾藏在雲底下。

## 節點內部

分兩欄：**元件欄**靠外側（寬約 150），**標註欄**靠內側。畫面右半邊的節點左右鏡射，鏡射公式是 x' = 1280 − x。

元件欄由上到下：

1. Pod 框 150×110，名稱在上，內含 120×60 的小框放 IP 與網卡名稱。
2. 一條黑色直線接到主機端 veth 框 150×56。
3. 其他元件（如 Kernel routing）150×48。
4. 上行介面 130×44，在節點底部置中；IP 以粗體放在右側。
5. 成員網卡 66×36，壓在節點底邊上（y=526–562），由上行介面以折線分支。

小標籤（ingress／egress）約 62–70×22，貼在所屬框的上緣角落，不蓋住框內文字。

### 多個 Pod

同一節點有多個 Pod 時橫向並排，每個 Pod 框縮到寬 120。超過 3 個時只畫與路徑有關的，其餘以「…」表示。

### 沒有 bond

上行介面就是實體網卡：直接把它畫成壓在節點底邊上的框，IP 放在右側，省略分支折線。

## 標註

- 寬度以最長一行估算：字數 × 7 + 70（17px 字）。
- 放不下就換行；不可把字縮到 15px 以下。
- 尾巴是三角形，底邊貼在標註框邊上，尖端指向目標元件的邊緣。
- 編號圓圈半徑 14，放在標註框左上，文字從圓圈右側 24 處開始。

## 路徑

虛線走元件欄與標註欄之間的空隙。每一段各自一條 path、各自一個箭頭，不要用一條長線串到底，因為中途會穿過元件框。路徑不可從標註框底下穿過；會撞到時移動標註框，而不是讓線繞遠路。

## 自我檢查

把頁面中的 `<svg>` 取出，將 CSS 內嵌進 `<defs><style>`（去掉 `html`、`body`、`svg` 這幾條頁面用的規則，否則有些轉檔工具會輸出空白圖），再轉成 PNG 來看。例如用 Python 的 `cairosvg.svg2png`。

看這幾件事：

- 文字沒有超出自己的框
- 虛線沒有穿過標註框或文字
- 小標籤彼此沒有重疊
- 每個尾巴尖端確實落在目標元件上
- 曲線都接進雲裡
