# 風格

目標是明亮、安靜、好讀：淺色底、扁平、細框線，無陰影、無漸層。顏色只用來區分「哪一條連線」，其他一律用中性色。

不要做的事（使用者明確否決過）：

- 深色主題。
- 文字壓在強調色的色塊上（例如紫底白字的標註框），不好讀。
- 太多顏色：橘色強調元件、紅色編號都拿掉了。

## 字型

`Calibri, Carlito, "Segoe UI", Arial, "Noto Sans CJK TC", "Noto Sans TC", "PingFang TC", "Microsoft JhengHei", sans-serif`

中文字型一定要放進字型清單，否則沒有中文字型的轉檔環境會顯示方塊。

| 用途 | 字級 |
|---|---|
| 圖標題 | 22px 粗體 |
| 節點名稱 | 20px 粗體 |
| 元件名稱（eth0、cilium-envoy） | 20px |
| 框內 IP、Pod 名稱 | 17–18px |
| 節點的附加 IP（Gateway IP 等） | 17px |
| 上行介面 IP | 20px 粗體 |
| 小字（hostNetwork、lxc 名稱） | 15px |
| 步驟第一行 | 17px 粗體 |
| 步驟第二行 | 16px |
| 註解 | 15px |
| 編號 | 16px 粗體 |

不可把字縮到 15px 以下。

## 顏色（預設 One Light）

| 用途 | 色碼 |
|---|---|
| 背景 | #fafafa |
| 元件框底色 | #f0f0f1 |
| underlay（bridge）底色 | #e5e5e6 |
| 一般文字 | #383a42 |
| 標題、節點名稱、強調文字 | #232324 |
| 次要文字（步驟第二行、註解） | #50525c |
| 框線、連接線 | #696c77 |
| 淡色（不經過的元件、分隔線來源） | #a0a1a7 |
| 連線 ① | #a626a4 |
| 連線 ② | #50a14f（當文字或編號時用 #3f8f3e，對比較夠） |
| 會變動的值的灰底 | #e1e1e5 |

**顏色的意義是「哪一條連線」，不是方向。** 經過 proxy（Envoy、Gateway）時，用戶端到 proxy 是一條 TCP 連線，proxy 到後端是另一條，兩條各用一色。只有一條連線時，整張圖只用紫色。

使用者要其他主題時，同一套角色換成該主題的淺色版，例如 Solarized Light（#fdf6e3 底、#6c71c4、#859900）或 Catppuccin Latte（#eff1f5 底、#8839ef、#40a02b）。仍然只用兩個強調色。

## 線條與方塊

- 節點外框：#696c77 2px，不填色。
- 元件框：#f0f0f1 底、#696c77 1.5px 框。
- 連線的終點元件（例如 cilium-envoy）：同樣是中性底，改用 #232324 2px 框強調，不用顏色。
- underlay：#e5e5e6 底、#696c77 1.5px 框、圓角 6，深色字。
- 路徑：3px 虛線，`stroke-dasharray="8 6"`，每段結尾一個同色實心三角箭頭。
- 不經過的元件（例如被 eBPF 繞過的 lxc）：#a0a1a7 虛線框，不填色，灰字，框下方加一行「連線 ② 不經過」。

## 步驟編號

- 白底圓圈，半徑 14，外框 2.5px 與數字都用所屬連線的顏色。
- 圖上只放編號，不放標註框；編號放在它說明的元件旁邊，不壓線、不壓字。
- 右側步驟欄用同樣的圓圈。

## 會變動的值

PID、Pod 名稱、Pod IP、ingress IP、lxc 名稱、來源埠這類「重啟、重建或每條新連線都不同」的值，用**灰底小框**標示：#e1e1e5、圓角 4，框比字寬左右各多 3px。

- 只標在左側的圖上與註解，**右側步驟說明不加灰底**（使用者要求）。
- 灰底依實際字寬繪製，用 `scripts/chips.mjs`，不要用估算寬度。
- 步驟欄最下方加兩行註解，第一行開頭的「灰底」兩字本身套灰底當圖例：
  - `灰底的值會變動：重啟、重建或每條新連線都不同`
  - `圖中是 <日期> <叢集> 實測，請以自己查到的為準`

## 文字

- 元件名稱、IP、網卡名稱照 spec 原樣，不改大小寫。
- 步驟文字逐字呈現。含 `<`、`>`、`&` 時記得做 XML 跳脫。
