# 風格

目標是看起來像一張乾淨的 PowerPoint 架構投影片：白底、扁平、細黑框線，無陰影、無漸層、無 3D。

## 字型

`Calibri, Carlito, "Segoe UI", Arial, sans-serif`

Carlito 與 Calibri 字寬相容，以 Google Fonts 載入作為沒有 Calibri 時的後備，這樣寬度估算在不同機器上才一致。

| 用途 | 字級 |
|---|---|
| 元件名稱 | 20px |
| 框內 IP 與網卡 | 18px |
| 小標籤 | 15px |
| 標註文字 | 17px |
| 上行介面 IP | 20px 粗體 |
| 編號 | 16px 粗體 |

## 顏色

| 用途 | 色碼 |
|---|---|
| 送出方向：標註底色、egress 標籤、虛線 | #7B5EA7 |
| 接收方向：標註底色、ingress 標籤 | #C5DC6B |
| 接收方向的虛線 | #9CC43A |
| 強調元件 | #F28C28 |
| 編號與圓圈外框 | #E02020 |
| 雲 | #595959 |
| 框線與一般文字 | #000000 |

接收方向的虛線比標籤深一階，是因為 #C5DC6B 的細線在白底上幾乎看不見。

顏色帶有方向的意義，所以同一張圖裡不要把紫色用在接收路徑上。

## 線條

- 元件框：黑色 1.5px，白底。
- 節點外框：黑色 2px，不填色。
- 路徑：3px 虛線，`stroke-dasharray="8 6"`，每段結尾一個同色實心三角箭頭。

## 標註

- 圓角矩形（rx=6）加三角形尾巴，同色、無外框。
- 標註內黑字。
- 編號是白底、紅框的圓圈，裡面紅色粗體數字。白底是為了讓紅字在紫色上讀得清楚。
- 紫色小標籤內用白字，綠色小標籤內用黑字。

## 文字

- 元件名稱、IP、網卡名稱照 spec 原樣，不改大小寫。
- 標註文字逐字呈現。含 `<`、`>`、`&` 時記得做 XML 跳脫。

## 標誌

不畫任何產品或專案的商標。需要標示時用中性的灰色六角形外框，或請使用者提供自己的標誌檔再嵌入。
